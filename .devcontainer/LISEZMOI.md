# Palette, version de test

Cette fenêtre est un ordinateur temporaire fourni par GitHub. Palette s'y installe et démarre toute seule : **vous n'avez rien à taper**.

## 1. Patienter

La première fois, l'installation prend **5 à 8 minutes**. Le terminal en bas de l'écran affiche les étapes (lignes `[Palette]`).
Les ouvertures suivantes prennent moins d'une minute.

## 2. Ouvrir l'application

Quand le terminal affiche **« Palette démarre »**, un nouvel onglet s'ouvre avec Palette.

S'il ne s'ouvre pas (bloqueur de fenêtres) : onglet **Ports** en bas de l'écran, ligne **Palette**, icône **globe** 🌐.

## 4. Tester sur un téléphone

Copiez l'adresse de l'onglet Palette (elle se termine par `-3000.app.github.dev`) et ouvrez-la sur le téléphone.
GitHub demande alors de se connecter avec **le même compte GitHub**.

Pour éviter cette connexion GitHub (par exemple pour faire tester un menuisier) : onglet **Ports**, clic droit sur la ligne **Palette**, **Port Visibility**, **Public**. L'adresse devient accessible à toute personne qui la connaît : repassez en **Private** après le test.

## Bon à savoir

- **Laissez le terminal ouvert** : le fermer arrête l'application. Pour la relancer, rechargez la page.
- Sans activité pendant 30 minutes, l'ordinateur temporaire se met en veille. Vos données sont conservées : rouvrez-le depuis [github.com/codespaces](https://github.com/codespaces), Palette redémarre seule.
- À chaque ouverture, la dernière version publiée de Palette est récupérée automatiquement.
- Les comptes GitHub gratuits disposent d'un quota mensuel gratuit, largement suffisant pour des tests. Quand vous avez fini, supprimez l'ordinateur temporaire depuis [github.com/codespaces](https://github.com/codespaces) (menu **…**, **Delete**).
